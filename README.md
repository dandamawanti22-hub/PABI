## Daftar Kode

### 1. Metode Array

File: `Metode_Array_027.php`

Kode ini digunakan untuk mempelajari metode array pada PHP.

Beberapa fungsi yang digunakan:

- `array_unique()` digunakan untuk menghapus data yang sama atau duplikat pada array.
- `array_reverse()` digunakan untuk membalik urutan elemen array.
- `shuffle()` digunakan untuk mengacak urutan elemen array.
- `count()` digunakan untuk menghitung jumlah elemen dalam array.
- `sort()` digunakan untuk mengurutkan elemen array.

**Kesimpulan:**  
Kode ini menunjukkan penggunaan beberapa fungsi PHP untuk mengolah dan memanipulasi data dalam array.

---

### 2. Associative Array

File: `Metode_Associative_Array_027.php`

Kode ini digunakan untuk mempelajari associative array pada PHP. Associative array menyimpan data menggunakan pasangan key dan value.

Beberapa fungsi yang digunakan:

- `array_values()` digunakan untuk mengambil nilai dari array.
- `array_keys()` digunakan untuk mengambil key atau kunci dari array.
- `array_merge()` digunakan untuk menggabungkan dua array.

**Kesimpulan:**  
Kode ini menunjukkan cara menyimpan dan mengolah data menggunakan associative array.

---

### 3. Function dengan 2 Argument

File: `Fungsi dengan 2 Argument_027.php`

Kode ini digunakan untuk mempelajari function dengan parameter.

Function `belanjaan()` memiliki dua parameter, yaitu:

- `$bahan` untuk nama bahan.
- `$jumlah` untuk jumlah bahan.

Function tersebut kemudian dipanggil beberapa kali menggunakan data yang berbeda.

**Kesimpulan:**  
Kode ini menunjukkan cara membuat function dengan parameter dan menggunakan function tersebut secara berulang dengan data yang berbeda.

---

### 4. Callback Function

File: `CallBack Function dengan method_$call_user_func()_027.php`

Kode ini digunakan untuk mempelajari callback function pada PHP.

Function `berteriak()` menerima `$callback` sebagai parameter. Kemudian `call_user_func()` digunakan untuk menjalankan function yang diberikan sebagai callback.

Kode ini juga menggunakan anonymous function yang disimpan dalam variabel `$panggil`.

**Kesimpulan:**  
Kode ini menunjukkan bagaimana sebuah function dapat menerima function lain sebagai parameter dan menjalankannya sebagai callback.

---

### 5. Callback Function dengan is_callable()

File: `Menguji fungsi Callback dengan method is_callable()_027.php`

Kode ini merupakan contoh callback function yang menggunakan `is_callable()`.

`is_callable()` digunakan untuk menguji apakah suatu nilai dapat dipanggil sebagai function.

Jika callback dapat dipanggil, program menjalankan callback menggunakan `call_user_func()`.

**Kesimpulan:**  
Kode ini menunjukkan cara melakukan pengecekan terhadap callback sebelum menjalankannya.
